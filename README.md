
# Intervexa AI

An AI-powered Technical Interviewer built using Python, Streamlit, FastAPI and Google Gemini.

## Features
- Multiple technical job roles
- AI-generated interview questions
- Interactive interview experience
- Instant AI-powered responses

## Technologies Used
- Python
- Streamlit
- FastAPI
- Google Gemini API

## Installation

1. Clone this repository.
2. Install dependencies:
   pip install -r requirements.txt
3. Configure your Gemini API key in a .env file.
4. Run the application.
